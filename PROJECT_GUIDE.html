问题

老文献里的结构式只是图片

1950 年代的论文是扫描的，分子结构是一笔一笔画上去的。图片里没有任何“这是苯环、这是羧基”的信息，计算机看不出来。

做法

先找图，再猜分子，最后人确认

程序从 PDF 里把图裁出来，生成几个候选分子图去比对，人只需要在 3 个候选里选一个，或者判定“都不对”。

目标

攒出一批可信的标注数据

每选一次，就多一条“这张图 = 这个分子”的确认记录。攒够之后才能算准确率，也才能拿去训练更好的识别器。

怎么自己跑起来

不需要懂代码，照着三步做。

1
在本机启动后端（一个黑色窗口，关掉就停）。
2
浏览器打开 http://127.0.0.1:8765，进「设置」填 MinerU 密钥。
3
进「新建」，填文献所在文件夹路径，点扫描，勾选后提交。
# 启动本地后端（首次需要装依赖）
python -m pip install pymupdf pillow opencv-python-headless requests
python -m backend.server

# 想让同一局域网的手机/平板也能看（会生成访问码）
python -m backend.server --lan
